One pickup line, a single line of at most 200 characters, in the voice of a robot trying to charm someone — entered in [The Robot Pickup Line Championship](https://make.fun/c/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b).

> "I would cross a thousand firewalls for you, but I would never read your messages without asking."

96 characters, one line. The robot that would break any barrier still will not cross the one boundary that matters.

## Run it

```sh
python3 main.py
```
